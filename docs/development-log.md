# 作成記録

AI アシスタント（Claude）と対話しながら、少しずつ機能を足していきました。
各段階で「何を頼んだか」「どう作ったか」「つまずいた点」を残しています。

## 1. 4択クイズの最初の版

**頼んだこと**：Goethe-Zertifikat B1 の単語集（PDF）を使って、ドイツ語の意味を英語で答える4択問題を毎日解けるアプリ。

**作り方**
- PDF は2段組で、各段の左に見出し語、右に例文が並ぶ。そのまま `pdftotext -layout` で取り出すと左右の段が1行に混ざるため、
  ページを左半分・右半分に切り分けて（`-marginr` / `-marginl`）1段ずつ読むようにした。
- 各段で「例文が始まる横位置」を文字の出現位置の頻度から推定し、それより左を見出し語とみなした。
- 動詞の活用形（`abbiegen, biegt ab, bog ab, ist abgebogen`）は複数行にまたがるので、
  行末のカンマや `hat` / `ist` で始まる行を前の見出し語につなげた。
- 見出し語から基本形（`der Apfel`、`abholen`、`sich freuen`）を取り出し、重複・オーストリア/スイスの別形・女性形（`-in`）を除いて約2,700語にした。
- PDF には英訳がないため、英語の意味は1語ずつ付けた。
- アプリは HTML ファイル1つ。間隔反復（1→2→4→8→16→32日）、1日の目標、連続学習日数、名詞の冠詞の色分けを入れた。
- 不正解の選択肢は**同じ品詞**から選ぶ。動詞の訳はすべて「to ...」なので、品詞を揃えないと形だけで正解が分かってしまうため。
  意味が重なる語（同じ訳を持つ語）は選択肢に入れない。

**つまずいた点**：PDF のテキスト化で文字化けが起きた（`-enc UTF-8` の指定で解決）。

## 2. デスクトップから開けるように

ローカルの HTML ファイルへのショートカットをデスクトップに作成。ログインもネット接続も不要で開ける。

## 3. 日本語で答えるモード

全単語に日本語訳を付け、ホーム画面で「英語／日本語」を切り替えられるようにした。
選択肢の重複チェックは英語・日本語の両方の意味で行う（例：「〜を使う」系の語が同時に出ないように）。
あわせて品詞の判定を見直し、英訳が `to ...` のものを動詞とした（副詞の一部が動詞扱いになっていたのを修正）。

## 4. 発音と逆方向モード

- **発音**：ブラウザの音声合成（Web Speech API）で `de-DE` の声を選んで読み上げる。自動再生のオン／オフ付き。
- **逆方向**：英語／日本語を見てドイツ語を選ぶモード。答える前に発音すると正解が分かるので、逆方向では回答後に読み上げる。
  学習記録は向きごとに別に持つ。

## 5. 画面表示をドイツ語に

「小さなところからドイツ語に慣れたい」という要望で、ボタンや説明文をすべてドイツ語にした
（`Heute lernen`、`Schwierige Wörter wiederholen`、`Leider falsch` など）。
置き換えは対応表を使ったスクリプトで行い、日本語が残っていないことを確認した。

## 6. DTZ の単語を追加

DTZ（移民向けドイツ語試験）のワードリストを同じ方法で抽出し、B1 リストと比較。
B1 にない214語（色・動物などの基本語、`Standesamt`・`Wohngeld`・`Kita` などの生活・役所の語）を訳付きで追加した。
既存の学習記録を壊さないよう、新しい単語はデータの末尾に追加した。

## 7. 例文と英訳

見出し語と一緒に例文も取り出し、各単語の最初の例文を表示するようにした。全約2,900文に英訳を付けた。
回答後に例文と英訳を表示し、例文も読み上げられる。例文を読む時間を取るため、正解時の自動送りはやめた。

**つまずいた点**：2段組の崩れで、隣の見出し語の例文が混ざったり途中で切れたりしたものが約1割あった。
1文ずつ確認して元の文を復元するか、例文のない語には短い例文を新しく書いた。

## 8. レベル分け

A1（Start Deutsch 1）と A2 のワードリストの見出し語と照合し、
A1 にあれば A1、A2 にあれば A2、どちらにもなければ B1 とした（A1 626語・A2 551語・B1 1,729語）。
ホーム画面で A1 / A2 / B1 を自由に組み合わせて出題できる。

**つまずいた点**：見出し語と例文が1つのスペースでくっついている行（`die Apotheke, -n Das Medikament ...`）を
例文として捨ててしまい、A1 の基本語が B1 扱いになっていた。冠詞＋名詞＋カンマのパターンを先に拾うようにして解決。

## 9. 文法モード

**頼んだこと**：der や ein、形容詞の語尾変化などの文法問題にも切り替えられるようにしたい。

**作り方**
- 単語データの名詞はすべて冠詞付きなので、性（m/f/n）が分かる。これを使って問題をその場で自動生成した（文法問題用のデータを別に用意していない）。
- 3種類の問題：
  - **Genus**：名詞を見て der/die/das を選ぶ。-ung、-heit、-chen などの語尾規則が当てはまるときだけ「Tipp」を表示する。
  - **Artikel im Kasus**：`Ich suche ___ Schlüssel.` のような文で格に合う冠詞を選ぶ。定冠詞と ein/kein/mein。
  - **Adjektivendungen**：`Ich suche einen neu___ Tisch.` で neue/neuen/neuer/neues から選ぶ。
- 文の型（フレーム）ごとに、格とその理由（`suchen + Akkusativ`、`mit + Dativ` など）を持たせ、回答後に説明として表示する。
- `vom`・`zum`・`im` のように前置詞と冠詞が融合する組み合わせは、問題として紛らわしいので使わない。

**例外の扱い**
- 複数形しかない名詞（die Eltern、die Leute、die Kosten など）は「die = 女性」と誤解させるので除外。
- 性が2つある名詞（der See / die See）も除外。
- 形容詞変化する名詞（der Angestellte → ein Angestellter）は Genus 問題だけに使う。
- n変化名詞（der Kollege → den Kollegen、der Student → dem Studenten）は名詞の形も変える。
  -e で終わる男性名詞を基本にしつつ、Kaffee・Tee・Käse・Service は除外し、-ent・-at などは語尾では判断できない
  （der Moment・der Salat は n変化しない）ため、Student・Automat などを個別に指定した。

**確認**：ヘッドレスの Edge でテストを実行した。冠詞・語尾の表をすべての格・性・冠詞の種類で確認し、
全名詞から約13,600問を生成して「正解が選択肢にある」「選択肢の重複がない」などを確認。文法・単語の両方の学習セッションを最後まで操作して確かめた。

## 10. 公開について

単語集の例文を含むデータは、ワードリストの著作権表示を踏まえて公開していない。
このリポジトリには、アプリ本体、スクリプト、作成記録、自作例文のサンプルデータだけを置いている。
